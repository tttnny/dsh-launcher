# 页面、状态与样式

管界面看得见的那一层：导航与跳转、状态怎么显示、样式写在哪里。业务规则不在这里——实例
这条记录见 `instances.md`，版本与插件见 `versions-and-homes.md`，跨机器的部分见
`hosts.md`。术语见 `GLOSSARY.md`（当前主机、资源库），导航的推理见 ADR-0004。

## 导航只有三个目的地：实例 / 资源库 / 设置

`src/router/index.ts` 是唯一的路由表，`src/shortcuts.ts` 是快捷键与后端 `menu-navigate`
载荷的唯一映射。旧路径（`/homes`、`/profiles`、`/versions`、`/tasks`）必须继续重定向；
托盘与原生菜单的载荷指向 `/library?tab=…`。`/plugins` **不在这份名单里**——它一直是插件页
本身（只由运行中的实例进入），别把它改成重定向。加第四项顶级导航前先读 ADR-0004。

**整个启动器只有一个「当前主机」**：状态住在 `src/stores/launcher.ts` 的 `currentHostId`，
资源库页头的选择器与实例页的主机筛选读的是同一份。资源库的三个标签页永远按它显示
（`store.versions` / `store.homes` 就是它的那两份，按主机缓存），**没有**「全部」这一档；
实例页的「全部」是 `store.allHosts` 开的一个视图。所以：加主机选择控件时只改 store 里这
一个状态，别再建第二个。

## 打开实例 = 用系统浏览器打开实例 URL

经 `open that`，与 `open_external` 同策略（先 trim 再只放行 http 与 https）。
`open_instance_window` 保留命令名和只传 id 的签名，后端从 running 表查 URL；不存在任何
实例 webview（回退史见 ADR-0002）。

**插件管理属于运行中的实例**：入口只有实例侧两处（详情页头部按钮、实例行上的按钮），且
只在实例 `running` 时出现；Profile 列表不放插件入口，只陈述「哪些实例默认用它」。跳转带
`?instanceId=` 与 `?from=`（`instances` / `instance-detail`，由 `usePluginLink.openPlugins`
写入），「返回实例」据此回到用户离开的地方：从实例行走就是「实例页 + `?focus=<id>`」
（那一行的卡片自动展开、滚动到位并闪一下），从详情页走就是回详情页。别再把它钉死到某一个
页面。

## 实例页的批量按「看得见的那一份」来

「全部启动 / 全部停止」作用于当前可见的行（主机筛选 × 搜索框），规则只有一份，住在
`src/instancesBulk.ts` 的 `bulkScope`（视图把 `filtered` 交给它，批量按钮、汇总计数都读它
的结果）。**主机不可达的行不进「全部启动」**：那种状态下启动器说不出那台机器上是不是已经
在跑，这一行自己的动作是「重试」——跳过要报出来，不能悄悄少做。可见集里没有可启动的行时
不显示「全部启动」（按钮不能承诺一件不会做的事）。两个批量动作做完都按实际结果报数：成功
几个、失败几个（附后端那句原因，不要被 `allSettled` 吞掉）、跳过几个不可达。

## 托盘是一份跨主机的清单

托盘「运行中」子菜单列出**所有主机**上运行中的实例，每行都带它跑在哪台机器上
（`打开：名字（主机 · Profile）`）——两台机器上的同名实例必须分得开。同一份清单决定双击：
只有一个运行实例时直达它，两台机器各有一个**不算**「只有一个」，显示主窗口（`sole_running`）。
托盘的「打开」走 `process::reachable_url_for`，「停止」走 `process::stop_instance_process`
（与主窗口同一套停止逻辑）。托盘没有页面可以报错，失败经 `tray::report_to_user` 用原生
对话框说；「停止全部」把失败合成一份清单，不弹一串对话框。托盘的「全部启动 / 全部停止」
**没有主机这一维**，但「全部启动」与页面同一条规则地**跳过不可达主机上的实例**并把跳过的与
失败的一起报出来。

## 插件页按「归属」分两组，状态不做分类

列表只有「你添加的」（`removable`，默认展开，行内可卸载）与「随 DSH 发布」
（`removable:false`，默认折叠，只报个数）——**不要**按 `enabled` 再切一个「未挂载」组：
挂没挂载是状态，开关和状态点已经说了，而且按状态分组的折叠会让刚被切掉的那一行从指针底下
跑掉。两组的组头都是折叠开关并带计数，所以折叠不等于隐藏；段标题报状态总数（「已挂载
N / M」）。写入返回 `restart-required` 时，页面顶部留一条「改动要重启才生效」的提示 +
重启按钮（实例状态一变就撤掉）。

## 颜色只表示状态

`src/styles/tokens.scss` 是唯一的调色板来源，机器事实（版本号、端口、URL、路径、条目 id）
一律加 `.dl-mono`。不要在视图里再写一份按钮/卡片样式——`.dl-btn`、`.dl-surface`、
`.dl-chip`、`.dl-status` 在 `src/styles/index.scss` 里定义一次（搜索框是
`.dl-input.dl-search`，实例列表与版本列表共用）。
